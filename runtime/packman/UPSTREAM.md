# Vendored Packman bootstrap

Linux bootstrap files `packman`, `python.sh`, and `bootstrap/install_package.py`
are from NVIDIA/cloud-native-docs at commit
`ca002206c61c3372d0ddc5ad8888afd200faa0f1`, directory `tools/packman/`:
https://github.com/NVIDIA/cloud-native-docs/tree/ca002206c61c3372d0ddc5ad8888afd200faa0f1/tools/packman

Their original Apache-2.0 notices are retained. `config.packman.xml` selects the
public NVIDIA CloudFront download endpoint. Windows bootstrap is out of scope.
